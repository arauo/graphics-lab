## 2. 指针算术

### 2.1 三条实测

`src/ptr_arith.c` 的输出：

```
sizeof(char)=1   sizeof(int)=4   sizeof(double)=8

pc+1 - pc = 1
pi+1 - pi = 4
pd+1 - pd = 8

sizeof(pc)=8  sizeof(pi)=8  sizeof(pd)=8

sizeof(a)=20  sizeof(pi)=8

a == &a[0] ? 1
a+1 与 &a[1] 相差 4 字节
```

**三个结论一次看完：**

| 指针 | `p + 1` 走几字节 | 原因 |
|---|---|---|
| `char *pc` | **1** | `sizeof(*pc)` = 1 |
| `int *pi` | **4** | `sizeof(*pi)` = 4 |
| `double *pd` | **8** | `sizeof(*pd)` = 8 |

### 2.2 公式

```c
p + 1  ←→  (char *)p + sizeof(*p)
```

**编译器把 `p + 1` 翻译成「地址加 `sizeof(*p)` 个字节」。**

所以指针算术**不是**「地址加 1」，而是「前进一个元素」。

### 2.3 指针自己恒为 8 字节

```c
sizeof(pc) == sizeof(pi) == sizeof(pd) == 8
```

**指针大小和你指向什么无关**，只和机器位数有关。x86-64 上地址是 64 位 = 8 字节。

> 这是上周踩过的坑：`char*` 不是「1 个指针 1 字节」。变的是 `sizeof(*p)` 和步长，不是指针本身。

### 2.4 指针相减用 `%td`

```c
printf("%td\n", pd + 1 - pd);      /* ✅ */
printf("%ld\n", (long)(pd + 1 - pd));  /* ⚠️ 能跑，但类型不对 */
```

两个指针相减，结果是 **`ptrdiff_t`**（有符号整数类型），对应格式符 **`%td`**。

`(long)` 在 64 位上碰巧也是 8 字节，但那是运气，不是正确。

### 2.5 指针相减的规则

```c
int a[5];
int *p = &a[1];
int *q = &a[4];
printf("%td\n", q - p);      /* 3 —— 相差 3 个元素，不是 12 字节 */
```

**结果单位是「元素个数」，不是字节数。** 想拿字节就自己乘 `sizeof(*p)`。

**⚠️ 只有指向同一个数组的两个指针相减才有意义。** 不同数组相减是未定义行为。

## 3. 数组名退化

### 3.1 三个看起来一样、其实不一样的写法

```c
int a[5] = {1,2,3,4,5};
```

| 写法 | 类型 | 值 | `+1` 走多少字节 |
|---|---|---|---|
| `a` | `int *`（退化后） | `&a[0]` | 4 |
| `&a[0]` | `int *` | `&a[0]` | 4 |
| **`&a`** | **`int (*)[5]`** | **`&a[0]`** | **20（整个数组）** |

**`a`、`&a[0]`、`&a` 三者「值」相同（同一个地址），但「类型」不同，所以 `+1` 的结果差得很远。**

```c
printf("%p %p %p\n", (void*)a, (void*)&a[0], (void*)&a);  /* 三个一样 */
printf("%td\n", (char*)(&a + 1) - (char*)&a);             /* 20 */
```

### 3.2 `&a` 是「指向整个数组的指针」

```c
int (*p)[5] = &a;      /* p 指向「含 5 个 int 的数组」 */
p + 1;                 /* 前进 20 字节，跳过整个数组 */
```

这个类型就是 **数组指针**，§4 会正式讲。

### 3.3 `sizeof(a)` vs `sizeof(p)`

```c
int a[5];
int *p = a;

sizeof(a)   /* 20 —— 数组本身的大小 */
sizeof(p)   /*  8 —— 一个指针 */
```

**为什么不同？** 因为 `a` 在 `sizeof` 里**不退化**。`sizeof` 是少数几个「数组名保持数组身份」的场合之一。

### 3.4 形参里的 `sizeof` 陷阱

```c
void f(int arr[]) {
    printf("%zu\n", sizeof(arr));   /* 8，不是 20！ */
}
```

**数组作形参时，`int arr[]` 等价于 `int *arr`**——数组名在这里**必然退化**，长度信息彻底丢失。

> **这就是为什么所有 C 函数都要额外传一个长度参数。** `strlen` 要扫 `'\0'`、`memcpy` 要传 `n`，根子都在这儿。

### 3.5 数组名不能赋值

```c
int a[5], b[5];
a = b;         /* ❌ 错误：数组名不是左值 */
a++;           /* ❌ 错误：数组名不是变量 */
```

**`a` 不是指针变量，它只是「在表达式里会退化成指针」。** 退化的结果是个临时值，没有存储空间，所以不能赋值、不能自增。

想改指向，必须用真正的指针：

```c
int *p = a;
p++;           /* ✅ p 是变量 */
```

### 3.6 「退化」到底退化成什么

| 场合 | `a` 的身份 |
|---|---|
| `sizeof(a)` | 数组（20） |
| `&a` | 数组（`int(*)[5]`） |
| 传给函数 | 指针（`int*`） |
| `a + 1` | 指针（`int*`） |
| `a[i]` | 指针（`int*`）再解引用 |

**口诀：除了 `sizeof` 和 `&`，`a` 在任何地方都退化成 `&a[0]`。**

## 4. 复杂声明：从里往外读

### 4.1 口诀

> **从变量名开始，先碰到 `[]` 就是数组，先碰到 `*` 就是指针；有括号就先看括号。**

### 4.2 四个例子

| 声明 | 读法 | 是什么 |
|---|---|---|
| `int *a[3]` | a 是 [3] 数组，元素是 `int*` | **指针数组** |
| `int (*p)[3]` | p 是指针，指向 [3] 个 int | **数组指针** |
| `int (*f)(int,int)` | f 是指针，指向「收两个 int 返回 int 的函数」 | **函数指针** |
| `int *g(int)` | g 是函数，返回 `int*` | **返回指针的函数** |

**注意最后两个的区别：** `(*f)` 的括号让 `*` 先和 `f` 绑定，所以 `f` 是指针；没有括号时 `g` 先和 `(int)` 绑定，所以 `g` 是函数。

### 4.3 `int *a[3]` vs `int (*p)[3]`（实测）

`src/decl_lab.c`：

```c
int x = 1, y = 2, z = 3;
int *a[3] = { &x, &y, &z };      /* 3 个指针，占 24 字节 */
int arr[3] = { 10, 20, 30 };
int (*p)[3] = &arr;              /* 1 个指针，占 8 字节 */
```

输出：

```
sizeof(a)  = 24      ← 3 × 8
sizeof(p)  = 8       ← 1 个指针
sizeof(*a) = 8       ← 一个 int*
sizeof(*p) = 12      ← 一个 int[3]
*a[1]      = 2
(*p)[1]    = 20
arr[1]     = 99      ← 通过 (*p)[1] 改了 arr
```

**两个关键对比：**

- `sizeof(a)` = 24，`sizeof(p)` = 8 → **一个是数组，一个是指针**
- `sizeof(*a)` = 8，`sizeof(*p)` = 12 → **`*a` 是 ptr，`*p` 是数组**

### 4.4 二维数组的 `m[1]` 是什么

```c
int m[2][3];
```

| 表达式 | 类型 | `+1` 走多少 |
|---|---|---|
| `m` | `int (*)[3]` | 12 字节（一整行） |
| `m[1]` | `int (*)[3]` 退化前是 `int[3]` | 12 字节 |
| `m[1][0]` | `int` | 4 字节 |

**`m[1]` 的类型正是 `int (*)[3]` 退化后的 `int[3]`** —— 所以 §4.3 的 `p` 就是「一行」。

```c
int (*p)[3] = m;        /* p 指向第 0 行 */
p++;                    /* 跳到第 1 行 */
printf("%d\n", (*p)[0]);/* m[1][0] */
```

### 4.5 函数指针

```c
int add(int a, int b) { return a + b; }

int (*f)(int, int) = add;      /* 函数名本身就是地址，不用 & */
printf("%d\n", f(2, 3));       /* 5，调用方式和普通函数一样 */
printf("%zu\n", sizeof(f));    /* 8 */
printf("%d\n", f == add);      /* 1 */
```

**三个事实：**

1. `add` 和 `&add` 的值相同（函数名求值时就是地址）
2. `f(2,3)` 和 `(*f)(2,3)` 都能调用
3. 函数指针的大小也是 8

### 4.6 `qsort`：为什么非要传一个函数

```c
void qsort(void *base, size_t nmemb, size_t size,
           int (*compar)(const void *, const void *));
```

**四个参数回答两个问题：**

| 参数 | 回答 |
|---|---|
| `base` | 从哪开始排 |
| `nmemb` | 一共几个元素 |
| `size` | 每个元素多大（用它算地址偏移） |
| **`compar`** | **两个元素谁排前面** |

**为什么第 4 个必须由你给：** `qsort` 是通用函数，它要同时能排 `int`、`double`、字符串、结构体。它只负责「搬」（交换内存块），**不负责「判」**（谁先谁后）。

```c
qsort(arr, n, sizeof(int),    cmp_int);     /* 整数 */
qsort(str, n, sizeof(char*),  cmp_str);     /* 字符串 */
qsort(rec, n, sizeof(Rec),    cmp_by_age);  /* 按年龄 */
```

同一个 `qsort`，三种行为。

### 4.7 比较函数的「三值」规则

**返回值不是「谁大」，而是「谁排前面」：**

| 返回值 | 含义 |
|---|---|
| **< 0** | `a` 排在 `b` 前面 |
| **= 0** | 相等，顺序随意 |
| **> 0** | `a` 排在 `b` 后面 |

```c
int cmp_int(const void *a, const void *b) {
    int x = *(const int *)a;
    int y = *(const int *)b;
    return (x > y) - (x < y);
}
```

| x | y | `(x>y)` | `(x<y)` | 返回 |
|---|---|---|---|---|
| 3 | 1 | 1 | 0 | **1**（3 排后面） |
| 1 | 3 | 0 | 1 | **-1**（1 排前面） |
| 2 | 2 | 0 | 0 | **0** |

### 4.8 为什么要 `(x>y) - (x<y)` 而不是 `x - y`

```c
int x = 2147483647;    /* INT_MAX */
int y = -2147483648;   /* INT_MIN */
x - y;                 /* 溢出，结果可能是 -1，排序直接错 */
```

**`(x>y) - (x<y)` 只产生 1 / 0 / -1，永远不溢出。** 这是标准库级别的写法，记住这个模式。

### 4.9 `void *` 是「通用指针」

```c
void *p = &x;      /* 任何地址都能装 */
*p;                /* ❌ 不能解引用：void 大小未知 */
*(int *)p;         /* ✅ 先转会真实类型 */
```

**`qsort` 用 `void*` 是因为它不知道元素类型**；比较函数的第一件事就是把它转回来。

## 7. 易错点总表

| 错误写法 / 想法 | 真相 |
|---|---|
| 「`p + 1` 就是地址加 1」 | 加的是 `sizeof(*p)` |
| 「`char*` 所以指针是 1 字节」 | 指针恒 8 字节，变的是步长 |
| 「`a` 就是指针」 | `a` 是数组，只在表达式里**退化**成指针 |
| 「`sizeof(a)` 在函数里也是 20」 | 形参里变成 8，长度信息丢了 |
| 「`&a` 和 `a` 一样」 | 值一样，类型差很多：`int(*)[5]` vs `int*` |
| 「`int *a[3]` 是指向数组的指针」 | 是**数组**，元素是指针 |
| 「`int (*p)[3]` 是 3 个指针」 | 是**一个指针**，指向 `int[3]` |
| 「指针相减得到字节数」 | 得到的是**元素个数** |
| 「函数指针要 `&add`」 | 不用，`add` 本身就是地址 |
| 「比较函数返回谁大」 | 返回**正负**，表示谁排前面 |
| 「`x - y` 也能当比较函数」 | 会溢出，用 `(x>y)-(x<y)` |

### 一个万能判断

> **看到 `p + 1`，先问：`*p` 是什么类型？多大？—— 答案就是步长。**
>
> **看到复杂声明，先从变量名往外读：先碰 `[]` 是数组，先碰 `*` 是指针，有括号先看括号。**

## 8. 验收自测（5 题）

### 题 1

```c
int a[5];
int *p = a;
```

`sizeof(a)`、`sizeof(p)`、`p + 1 - p` 各是多少？

### 题 2

`int *p;` 那么 `p + 1` 比 `p` 大多少字节？把 `p` 换成 `double *` 呢？由什么决定？

### 题 3

`&a` 的类型是什么？`&a + 1` 比 `&a` 大多少字节（`a` 是 `int a[5]`）？

### 题 4

```c
int *a[3];
int (*p)[3];
```

分别是什么？`sizeof(a)` 和 `sizeof(p)` 各是多少？

### 题 5

`qsort` 的第四个参数为什么要传一个函数？这个函数返回值**正数**代表什么？

---

### 答案

**题 1**：`20`、`8`、`1`（指针相减得到元素个数）

**题 2**：4 字节；8 字节。由 `sizeof(*p)`（也就是 `*p` 的类型）决定。

**题 3**：`int (*)[5]`；20 字节（跳过一个完整数组）。

**题 4**：`int *a[3]` 是「3 个 `int*` 组成的数组」，`sizeof` = 24；`int (*p)[3]` 是「一个指针，指向 `int[3]`」，`sizeof` = 8。

**题 5**：因为 `qsort` 是通用的，它只负责搬内存，不知道你按什么排；比较函数返回**正数**表示「第一个参数应该排在后面」。

## 11. 一句话

> **指针算术的单位是「元素」不是「字节」，步长由 `*p` 的类型决定；数组名只在 `sizeof` 和 `&` 面前保持身份，其余场合一律退化成首元素地址；复杂声明的读法是从变量名往外走，先碰 `[]` 是数组，先碰 `*` 是指针。**
